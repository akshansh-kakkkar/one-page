## Description

Its a platform where you can create your custom pages to create a memory of the year.

## How One Page works

- User enters all the details in the form
- User is able to view a good looking page of the information which they enter

## Features

- Add an Image
- Add a title
- Add a description
- View the combined data into a new page

## Tech Stack

- Next JS
- Tailwind Css
- Github
- Git

## How it was made

I started with making a landing kind of a page and after that I added a link which redirects the person where user selects the year form I have added that there because I am planning to add more themes to the custom page and then user fills the info and then the data is shown on the custom page.

## Installation

Prerequisites

- You need to install Node.js in your device

1.  Clone the Repository
```
git clone https://github.com/akshansh-kakkkar/one-page.git
```

2. Install the dependencies
```
bun install
```

3. Run the server
```
bun run dev
```

4. You are all set!
